# GameNative Duo for Balatro

Lovely mod (Balatro 1.0.1) installed by GameNative Duo's "Dual screen" switch. The table (HUD, jokers, the played
hand, deck) stays on the top screen; your hand, its buttons, the hand info, consumables, shop, blind select, cash
out, booster packs and the menus that fit go to the bottom screen, which you play by touch or with the controller.
With a normal window it changes nothing.

Part of GameNative Duo (GPL-3.0). The layout ideas (what goes on which screen, a larger hand, hand info below) and
two findings (the `can_skip_booster` crash on a removed pack, tooltips opening off the panel) come from
[rosbean/balatro-dualscreen](https://github.com/rosbean/balatro-dualscreen) (GPL-3.0); no code was copied.
