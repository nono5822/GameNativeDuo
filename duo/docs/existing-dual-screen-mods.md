# Existing dual-screen mods for PC games

From the community catalog https://github.com/codm2000/Dual-Screen-Games (read 2026-10-28). That list is mostly Android
ports for dual-screen Android handhelds such as the AYN Thor; only the entries below involve PC games. Its 🤖 tag
means the project used AI. Each project keeps its own licence.

| Project | Game | What it does | Link | PC status |
|---|---|---|---|---|
| Balatro Dual Screen (rosbean) | Balatro | Hand, shop, booster packs and menus on the second screen | github.com/rosbean/balatro-dualscreen | Needs a Steam, macOS or `.love` copy: a desktop mod. We bundle our own Balatro mod. |
| OpenMW-DS | The Elder Scrolls III: Morrowind | OpenMW fork: interface, inventory/magic, character, quests, live map | github.com/Josh-Daniels/OpenMW-DS | Open-source engine fork; platform not stated |
| Skyrim Web Monitor | The Elder Scrolls V: Skyrim | Character, inventory/magic, quests and a live map on a second screen | github.com/andreyvelsk/SkyrimWebMonitor | Platform not stated; a reference for a Skyrim companion |
| Minecraft Second Screen | Minecraft Java Edition | Mod for JE 1.21.11 + companion app: HUD and containers, live map, chat/inventory/hotkey tabs | github.com/exojosh/AynThorSecondScreen | Java Edition is PC software; targets the Ayn Thor |
| Fallout Pip-Boy | Fallout 4 (GOG) | Official companion app for the GOG edition | (APK reupload only) | Android companion for a PC game |

Not PC, for reference: Dusklight Dual Screen (Twilight Princess fork), Silksong Android (Android port), Showdown-DS
(browser), the emulator entries (PokeDaisy, Super Metroid Android, Zelda 3 Android) and Eden Duo companions for Switch
games (github.com/igawa6/eden-duo-companions: the main design reference for our companion framework, task 04).
