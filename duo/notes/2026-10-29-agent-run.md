### Bugs found and fixed during testing

- The IME never serves a bottom-screen window while the game has focus on display 0 (even with the window made
  focusable): text input moved to a main-screen dialog.
- Chip rows clipped at the bottom (LinearLayout baseline alignment).
- Page and card ids shared one namespace (`notes` card on a `notes` page became `notes-2`, which keys user state).
- `force-stop` skips the session end, so a running stopwatch kept counting while the game was closed: the next session
  now pauses it at the state file's last write, and a running timer writes the state once a minute.
- A page rebuild (a `when` flipping) reset the scroll position; problem lines named generated ids instead of the card's.
- `adb push` cannot create folders under `Android/data/<pkg>`: documented (`mkdir -p` first), for `duo-dev push`.
