presents, so screen split, the bottom-screen output and region views cannot work. Fix (92b69a165): the Dual screen
toggle sets the container to X11 and records `previousDisplayServer` in the undo record; turning it off restores it
unless the user changed it since. `DualScreenHost` logs a warning for Gamescope sessions. **Not device-tested** (all
test containers predate Gamescope and migrated to x11); verified by build and duo unit tests only.

## Task 3: one Dual screen control per game, mod explorer, official badge, voting

Picked up from an earlier attempt that left model-only WIP (`ModHub.kt`, rating/compat parsing; commits
`a39c43b7c`, `2e7928072`). Reviewed and kept it, with fixes (below), and built the UI. Commits `6900779f3`
(app), `c9744870d` (docs, official pin, community-repo proposal). Upstream files: none touched (the existing
`DualScreenToggle(...)` hook in `LibraryAppScreen.kt` is unchanged).

### What changed

- **One control**: `DualScreenToggle` is now a switch (with the selected mod's name under "Dual screen") joined
  to a chevron. Games with only community packages get it too; a game with only layouts gets just the chevron.
- **Explorer** (`ModExplorer.kt`, state in `ModHubState.kt`) replaces `CommunityPackagesSheet`: "Mods (the switch
  uses one)" and "Layouts and add-ons" sections; sort "Best on <device>" (default) / Top rated (Wilson) / Newest;
  cards with badges (✓ OFFICIAL in logo blue, Community, Code mod, Experimental, kind), author/version/size/date,
  rating "👍 N% of M votes · K comments", device compatibility, what it changes, state (On / Selected / Applied /
  Update x). Detail page: description, screenshots (Coil, lazy), changelog, turn on/off, switch, update, apply,
  remove, open in browser, share, vote or report (browser or QR).
- **Switching** (`ModHub.switchTo`): undo the current mod through `DuoModInstaller`'s record, install the next; on
  failure the previous one is reinstalled. Code mods ask for consent once per package version.
- **Official**: bundled, `CommunityIndex.OFFICIAL_PACKAGES`, or the signed game file's top-level `official` list.
  Unit test shows a package entry's own `"official": true` is ignored.
- **Offline**: the cached list shows at once with its age ("List checked 5 minutes ago" / "Offline: list from …");
  the game page never waits on the network (refresh in the background when older than 6 h, always when opened).

Fixes to the WIP: `turnOff` removed a settings package on any game without a bundled mod, even when a community
code mod was what was on; now only when the settings package is the active switch entry. `checkedAt` falls back to
the cached list's own time for caches written before the marker.
