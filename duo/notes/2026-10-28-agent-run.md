### Gamescope (new upstream display server)

Bionic containers can now run under Gamescope, the default for new containers. Under it the X renderer never
presents, so screen split, the bottom-screen output and region views cannot work. Fix (92b69a165): the Dual screen
toggle sets the container to X11 and records `previousDisplayServer` in the undo record; turning it off restores it
unless the user changed it since. `DualScreenHost` logs a warning for Gamescope sessions. **Not device-tested** (all
test containers predate Gamescope and migrated to x11); verified by build and duo unit tests only.
