### Bugs found and fixed this session (1007)

- The bundled shared Unity plugin predated the WIP (no `UiRouter.PluginElements`): the HK plugin would have failed
  to load its live map element. Rebuilt against Slime Rancher's Managed and bundled.
- Live map was last in the editor's element list (after hundreds of HK elements): mod elements now come first
  (Thor and PC editors).
- Six option rows covered the whole bottom screen in the editor: folded behind "Settings".
- `GameManager.IsGameplayScene()` cost 0.21 ms per frame (most of the map's cost): cached per scene + 4x/s. Camera and
  overlay writes only when something changed.
